# Contributing

Submit source changes and reproducible synthetic tests. Run `sh tests/run.sh`, QTest when board code changes, and `python tools/verify_release.py` after refreshing the source inventory. Distinguish firmware-free, original-firmware QEMU and physical-device validation.

Do not upload firmware, camera dumps, extracted fonts/icons, calibration, keys, private images or memory/session traces to public issues or pull requests. Use generated inputs. See NOTICE.md and COPYING.
